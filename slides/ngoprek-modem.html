Prolog

Awal mula: satu video TikTok.

01Temuan. Scroll TikTok berhenti di satu barang: modem WiFi 4G ODM seharga ±Rp100 ribu — fungsi dasar lengkap, kelihatannya biasa saja.
02Kenyataan. Tidak ada fitur SMS. Tidak ada terminal. Cuma apa yang pabrik mau sertakan — titik.
03Keputusan. Keterbatasan itu justru memotivasi: di dalamnya ada Android utuh — kemampuan yang hilang kita tambahkan sendiri.
“Tidak ada SMS, tidak ada terminal — ya berarti kita yang tambahkan.” — keputusan yang jadi titik awal talk ini
Motivasi

Modem murahan itu komputer yang menyamar.

Di balik casing plastik dan satu lampu LED, ada Android utuh yang sudah root. Kita cuma perlu tahu di mana pintunya.

Harga ±Rp100rb

Modem WiFi 4G dijual murah dan bebas. Isinya SoC Qualcomm sungguhan — bukan gadget mainan.

Sudah root

adbd berjalan sebagai uid 0 — shell penuh tanpa unlock bootloader, tanpa flash apa pun.

Linux utuh

Android 4.4.4 + kernel 3.10: shell, BusyBox, web server embedded, PTY — semuanya bisa disentuh.

Rute

Lima fase, satu modem.

Fase 01 — Dump

Backup dulu, nekat kemudian.

terminal — adb root shell
# peta partisi (khas Qualcomm: by-name, bukan /dev/block/by-name)
$ ls -l /dev/block/bootdevice/by-name/
modem -> mmcblk0p1   boot -> mmcblk0p22 ...

# dump per partisi → file, lalu tarik ke laptop
$ dd if=/dev/block/mmcblk0p1 of=/sdcard/modem.img
$ adb pull /sdcard/modem.img .

# ulangi untuk semua partisi = snapshot penuh eMMC

Fase 02 — Bedah

Baca dulu otaknya, baru oper.

MifiService.apk — server yang bersembunyi

Jetty embedded di dalam APK OEM. Seluruh kontrol device lewat satu endpoint JSON:

POST /ajax
{"funcNo":1005, "net_mode":"0|1|2"}  # auto/3G/4G
{"funcNo":1001}  # status · rssi · operator
{"funcNo":2001}  # enable ADB (permanen!)
tooljadx 1.5.6 hasilapps/mifiservice-decompiled/

Channel AT — bisik langsung ke baseband

Binary /system/bin/modem_at adalah pintu AT yang sama dipakai APK internal:

shell di modem
$ modem_at AT^SYSCONFIG?
^SYSCONFIG: 11  # 11=auto, 2=wcdma-only, …
$ modem_at AT+COPS=?
…,7,...  # AcT 7 = E-UTRAN (LTE)
jalur/dev/smd11 catatanscan penuh butuh 30–120 detik

Kode OEM yang di-decompile = dokumentasi terbaik yang tidak pernah ditulis: dari situ ketahuan siapa yang menulis file mana, dan kapan.

Fase 03 — Modify

Web root-nya kita tulis ulang.

Yang berubah di jetty2/

↻index.html & main.html — login & shell di-rewrite total, valid HTML
+sms.html · ussd.html · terminal.html — halaman baru yang tidak ada di firmware
+restu-v5.css — design system sendiri, diinject paling akhir menimpa CSS legacy
gotchacharset gb2312 → operasi byte, bukan teks gotchajangan <html lang="en"> — translator JS menimpa dokumen gotchatemplate Jetty %{eval:…}% → jaga verbatim
boss fight

extractAssets() menimpa semuanya tiap boot

Setiap Jetty start, APK menyalin ulang assets/jetty2/ ke web root — semua modifikasi hilang tiap reboot. Tanpa cek versi.

solusi — status file
$ chown root:root file && chmod 755 file
penimpa oleh uid system → gagal silent
✓ modifikasi survive reboot (terbukti)

Jetty hanya butuh file world-readable; penulis assets hanya bisa menulis miliknya sendiri. Satu trik ownership = persistensi permanen.

Fase 04 — Extend

mifi-helper: API kita menempati port 8080.

REST + WebSocket

sms
GET /api/sms/list · POST /api/sms/send · delete
ussd
POST /api/ussd — dialog dibaca AccessibilityService
shell
POST /api/sh — exec non-PTY, fallback uid app
pty
WS /api/pty — terminal interaktif sungguhan
auth
header X-Auth · PIN · lockout 5× gagal / 5 menit
bonusBusyBox v1.31 → symlink applet ke filesDir/bin shimwhoami dari BusyBox rusak → dibungkus skrip id

PTY di Android 4.4 — tidak disediakan? bikin sendiri.

Bionic tidak punya openpty/forkpty — PTY-nya dirangkai manual di libmifipty.so:

mifi_pty.c
open("/dev/ptmx")  → TIOCSPTLCK unlock
TIOCGPTN           → /dev/pts/N
fork + setsid + TIOCSCTTY + dup2
execve("/system/bin/sh", ["-i"])

Dijembatani ke browser via WebSocket RFC 6455 tulisan tangan. Hasil: vi, top, resize otomatis (SIGWINCH) — semua jalan di tab browser.

Fase 05 — Deploy

Modem 2.0: yang lahir dari ngoprek.

▸ SMS Manager

Kirim / baca / hapus dari web UI, auto-refresh, kartu responsif. Teruji kirim nyata.

▸ Web Terminal

xterm.js + PTY asli: vi, top, Ctrl+C, resize ikut jendela. Modem jadi punya konsol.

▸ USSD Runner

Pipeline lengkap dengan pembaca dialog — dengan satu catatan besar (slide berikutnya).

▸ Internet USB ke Mac

macOS tak punya driver RNDIS → gadget di-switch ke CDC-NCM + bridge, Mac dapat IP dari modem.

▸ Tools AT

AT^SYSCONFIG, AT+COPS=? — kendali RAN & scan operator tanpa aplikasi OEM.

▸ Deploy 1 perintah

scripts/deploy-web.sh — push + chown + chmod. Factory reset? jalankan lagi.

semua fitur hidup di atas firmware stok — tanpa flash ulang, tanpa hard brick risk
Studi kasus

Jalan buntu itu juga temuan.

USSD dipilih sebagai ujian pipeline berikutnya. Ceritanya begini:

✓Pipeline jalanUSSD terkirim, dialog responsnya terbaca via AccessibilityService — end-to-end hidup.
✗Firmware data-onlyMesin CSFB ada di dalam firmware, tapi konfigurasi produk membuatnya tak pernah dieksekusi — modem me-release USSD instan di LTE.
✗Workaround matiTrik lama "3G only" dulu bisa memaksa CSnD — kini semua operator di area ini LTE-only, tak ada jaringan 3G untuk dipaksa.
status: won't fix — di level firmware autopsidocs/ussd-csfb-analysis.md — bukti dari decompile + log jalur resmikebutuhan operator → lewat SMS
Lessons

Yang bisa dibawa pulang.

01Dump sebelum opIMEI dan kalibrasi radio hidup di modemst1/2. Backup lengkap = berani eksperimen.
02Decompile duluKode OEM adalah dokumentasi yang tidak pernah ditulis — pahami alur file & service sebelum nekat.
03Persistence butuh trikYang menentukan survive-reboot bukan isi file, tapi siapa yang boleh menimpanya saat boot.
04Platform jadul → rancang sendiriTak ada openpty? Bikin dari /dev/ptmx. Tak ada applet? Shim BusyBox. Semua jadi bahan belajar.
05AI menulis kode, layer bawah tetap milikmuModel bahasa bisa generate aplikasinya; yang memahami partisi, PTY, dan channel AT tetap manusia.
